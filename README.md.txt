# Morse Code Translator

A simple Python command-line application that converts English text into Morse code using dictionaries and loops.

## Features

- Converts letters A-Z to Morse code
- Converts numbers 0-9 to Morse code
- Supports spaces between words
- Detects invalid characters
- Allows users to translate multiple messages without restarting the program

## Technologies Used

- Python 3

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/maryfavs/morse-code-translator.git
   ```

2. Open the project folder.

3. Run the program:

   ```bash
   python main.py
   ```

## Example

**Input**

```
HELLO WORLD
```

**Output**

```
.... . .-.. .-.. --- / .-- --- .-. .-.. -..
```
